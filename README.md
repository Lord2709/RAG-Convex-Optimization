# Convex Optimization for Retrieval-Augmented Generation Pipeline Tuning

> A study of convex and non-convex optimization structure in RAG retrieval signal weighting. We formulate the problem of learning retrieval weights as a constrained Quadratic Program (QP), characterize where convexity holds and where it breaks down, and empirically measure the relaxation gap on TriviaQA.

---

## Overview

Retrieval-Augmented Generation (RAG) pipelines combine multiple retrieval signals — dense cosine similarity, sparse BM25 lexical matching, and MMR diversity — whose weights are typically set by hand. This project asks: **what is the true optimization structure of this weighting problem, and how much does a convex formulation lose compared to a non-convex one?**

We show that:
- The full problem (joint selection + weight learning) is **non-convex and NP-hard**
- The weight learning subproblem (with fixed features) is a **strongly convex QP** with a unique global minimum
- The convex relaxation gap is **2–3%** on Recall@k — small but measurable
- Both optimizers drive the **MMR diversity weight to zero** on single-answer factual QA, which is a genuine empirical finding about when diversity signals add value

## Lambda (Regularization) Sensitivity Analysis

A key contribution of this project is a systematic study of how the regularization parameter λ affects the QP solution. We sweep λ ∈ {10⁻⁴, 3×10⁻⁴, 10⁻³, 3×10⁻³, 10⁻², 3×10⁻², 10⁻¹, 3×10⁻¹, 1, 3, 10} and record:

- **Regularization path**: how each learned weight [w_cosine, w_bm25, w_diversity] changes with λ
- **Objective value**: cost ‖Xw*−y‖² + λ‖w*‖² at the optimum as a function of λ  
- **Recall@5**: training retrieval quality at each λ (peak identifies the best regularization strength)
- **Weight composition**: stacked-area view of how λ blends the three retrieval signals

This is saved as `fig8_lambda_sensitivity.png` and `results/lambda_results.json`. The analysis is automatically run in Stage 4b of `main.py`.

**Key finding:** The MMR diversity weight remains near zero across all λ values on TriviaQA single-answer QA, confirming that diversity signals add no value for this task regardless of regularization strength. The cosine/BM25 split evolves with λ: at extreme λ, regularization forces weights toward [1/3, 1/3, 1/3]; at small λ, the less-regularized solution allocates weight more aggressively based on empirical signal strength.

## Optimization Formulation

**Convex subproblem (weight learning):**

Given pre-computed feature matrix X ∈ ℝⁿˣ³ with columns [cosine_similarity, BM25, MMR_diversity] and binary relevance labels y, we solve:

```
minimize   ‖Xw − y‖² + λ‖w‖²
subject to w ≥ 0,  Σwᵢ = 1
```

This is a **strongly convex QP** (λ > 0) with constraints on the probability simplex. Solved via CVXPY + OSQP with a guaranteed unique global optimum.

**Why the full problem is non-convex:**
1. Selecting the optimal subset of k documents from n candidates is combinatorial (NP-hard)
2. The downstream generation loss is non-differentiable with respect to w when selection is a function of w

**Non-convex comparison:** We also optimize w directly on Recall@k using Nelder-Mead (gradient-free), which maximizes a non-differentiable, non-convex objective. The gap between the two approaches is measured as the *relaxation gap*.

## Systems Compared

| System | Description |
|---|---|
| **Convex QP** | Weights learned via constrained QP (our main contribution) |
| **Non-Convex** | Weights learned by directly maximizing Recall@k (Nelder-Mead) |
| **Equal Weights** | Uniform w = [1/3, 1/3, 1/3] — naive baseline |
| **Cosine Only** | w = [1, 0, 0] — dense retrieval only |
| **BM25 Only** | w = [0, 1, 0] — sparse retrieval only |

## Dataset

- **TriviaQA** (`rc.wikipedia` split) via HuggingFace Datasets
- Wikipedia evidence pages used as the retrieval corpus
- Documents from all queries are pooled together, making retrieval non-trivial (each query must find its evidence among other queries' documents acting as distractors)
- Relevance labels derived from exact-match / token-F1 between document content and gold answers
